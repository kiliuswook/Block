# 피그마 UI 적용 — 기획 확인이 필요한 항목 (2026-09-28)

피그마 파일: https://www.figma.com/design/q0J4VMZ833DcNfGiQRqOSX (Page 1 가로 26장 + UI kit)
가로(1920×1080) 화면을 코드에 적용하면서, **디자인과 지금 게임 규칙이 어긋나 기획 판단이
필요한 것**은 손대지 않고 여기 모아 뒀다. 작은 차이는 디자인 쪽에 맞췄다(아래 "맞춘 것").

## 질문 (결정 필요)

1. **재화 알약의 `+` 버튼** — 디자인은 골드·캔 알약마다 `+`가 붙어 있다. 인앱 결제(충전)를
   뜻하는가? 지금은 눌렀을 때 상점 페이지를 여는 것으로 임시 연결했다 (`user_hud.gd`
   `plus_pressed` → `title.gd`). 결제가 없다면 `+`를 뺄지 결정 필요.
2. **레벨업 보상** — 디자인 팝업(`팝업_레벨업`)은 키캡 1장 + 캔 +5를 보상으로 보여 준다.
   지금 게임의 레벨업 보상은 **골드뿐**(`Account.level_reward()`)이고 캔은 주간 랭킹 시상에서만
   나온다. 레벨업 팝업은 골드 칩 하나로 만들어 뒀다 — 키캡·캔을 레벨업 보상에 넣을지?
3. **커스텀 슬롯 값** — 디자인의 나만의 냥이 슬롯 줄에는 잠긴 슬롯에 `50,000`(캔 아이콘)
   값이 붙어 있다. 지금은 `+` 타일로 **무료**로 슬롯을 연다(최대 3). 슬롯을 캔/골드로 파는
   것으로 바꿀지, 값은 얼마인지?
4. **인게임 타이머** — 디자인 인게임 상단에 `3:00` 타이머가 있다. 스테이지 모드에는 시간
   제한이 없다. 시간 제한을 넣을 계획인가? (넣지 않았다)
5. **홀드(블록 저장)** — 디자인 조작 안내에 `V / H 블록 저장/홀드`가 있다. 캣트리스 보드에는
   홀드가 없다(`escape_board.gd`는 `hold_piece`를 읽지 않는다). 조작 안내는 실제 키 바인딩으로
   그리게 바꿨다. 홀드 기능을 추가할지?
6. **일시정지 메뉴** — 디자인은 딤 + `일시정지` + [타이틀로][이어하기]뿐이다. 예전엔 일시정지에서
   음량·조작을 바꿀 수 있었는데 디자인대로 뺐다. 인게임에서 음량 조절이 필요하면 설정 버튼을
   하나 더 둘지?
7. **캐릭터 격자의 `Lv.04 해금`** — 디자인은 잠긴 냥이에 계정 레벨 해금 문구가 있다. 지금
   해금은 **키캡 A~Z 한 바퀴**뿐이라 `▦ n/26`으로 그렸다. 계정 레벨 해금 조건을 따로 둘지?
8. **캐릭터 타일의 선물 뱃지** — 디자인 격자 타일 좌상단에 빨간 선물 뱃지가 있다. "받을 보상이
   있다"는 뜻으로 보이는데, 지금 시스템에는 "받기" 단계가 없다(한 바퀴 채우면 즉시 등급이 오른다).
   뱃지 의미가 무엇인지?
9. **랭킹의 `STAGE 48`** — 스테이지 모드 랭킹 줄에 도달 스테이지가 점수 옆에 붙어 있다. 지금
   보드 엔트리는 점수만 올린다(`Ranks.submit(mode, value)`). 스테이지 수를 같이 올리려면
   보드 형식·서버 스키마가 바뀐다 — 넣을지?
10. **닉네임 규칙 문구** — 디자인은 "2~8자, 영문과 숫자 조합 4~10자까지"로 두 숫자가 모순이다.
    지금 코드는 최대 12자(`_nick_edit.max_length`)다. 규칙을 정해 주면 문구·길이를 맞추겠다.
11. ~~**폰트**~~ — **해결 (2026-09-28)**: Paperlogy 4/6/7/8/9(SIL OFL, fonts-archive/Paperlogy)를
    `shared/assets/fonts/`에 넣었다. 남은 것: 학교안심 둥근미소는 시안에서 `/` 구분자에만 쓰여서 받지
    않았고, Pretendard(캐릭터 소개·단계 태그 몇 곳)도 Paperlogy로 대신한다. 따로 원하면 알려 달라.
12. **모드 선택 카드의 미리보기** — 디자인은 빈 남색/회색 판이다. 지금은 코드로 우물·블록·냥이를
    간단히 그려 넣었다. 실제 미리보기 이미지를 받을지, 이대로 갈지?
13. **랭킹 팝업의 뒤 배경** — 디자인은 회색 딤(#676767) 위에 팝업이 뜬다. 지금은 그대로 했는데
    상단 HUD(Lv 카드·재화)가 팝업 위에 같이 보인다(HUD는 별도 레이어). HUD를 팝업 동안 가릴지?
14. **상점 고급 뽑기의 유니크 냥이 고르기** — 디자인의 고급(캔) 열에는 기계 판·스테퍼·뽑기 버튼뿐이고
    냥이를 거는 줄/버튼이 없다. 지금 캔 뽑기는 유니크 냥이 1종을 걸어야 돌아가서, **기계 판을 누르거나
    걸지 않고 뽑기를 누르면** 고르기 팝업이 뜨게 해 뒀다. 고급 뽑기를 "유니크 냥이 중 무작위"로 바꿀지,
    선택 열처럼 캡슐 줄 + 고르기 버튼을 디자인에 넣을지?
15. **뽑기 결과에 키캡 글자** — 디자인 결과 팝업에는 캡슐 속 냥이만 있고, 어떤 **글자(A~Z)** 키캡이
    나왔는지가 없다. 키캡 글자가 수집의 단위라 열린 캡슐 오른쪽 아래에 작은 키캡 칩을 얹어 뒀다(등급이 오른
    뽑기는 빛난다). 빼도 될지, 디자인에 자리를 따로 둘지?

## 디자인에 맞춘 것 (작은 시스템 변경)

- 메뉴 카드 4장 → 디자인 문구(`캐릭터 변경하기` · `상점 가기` · `랭킹 보기` · `설정 하기`)로 새 번역 키
  `MENU_BTN_*`. `캐릭터 변경하기`가 예전 무대 좌석 버튼 몫(좌석 배정 모드로 캐릭터 페이지)이다.
- 타이틀에 **스플래시**(로고 + Press to play)가 생겼다 — 아무 키/터치로 메뉴로.
- 캐릭터 페이지가 **탭 둘**(일반 냥이 / 나만의 냥이)로 갈라졌고 격자는 4열이다. 대표 캐릭터는
  ★ 대신 노란 `대표 캐릭터 설정/해제` 버튼 — 해제를 위해 `GameState.set_feature_cat("")`을 허용했다.
- 닉네임 변경이 랭킹 팝업의 줄에서 **Lv 카드 ⚙ → 닉네임 변경 팝업**으로 옮겨 갔다.
- 랭킹 팝업 구성: [주간|누적] 탭 → 색 프레임 안 [스테이지 모드|무한의 계단] → 목록(1~3위 메달 그림).
- 인게임 계기판: 흰 카드 + 남색 NEXT 판 + 줄 구분선 + `TOP SCORE` 트로피, 좌하단 **조작 안내 카드**는
  실제 키 바인딩(`KeyBinds`)으로 그린다. 인게임 상단은 Lv 카드만 — 지갑 알약은 결과창이 뜰 때 나온다.
- 결과창: 유령 냥이 그림 + 통계 판(SCORE/LEVEL/LINES 세 열) + 코인 줄 + 경험치 게이지 +
  [타이틀로][다시 도전]. 레벨이 오르면 정산 끝에 **레벨업 팝업**(별 + 골드 칩 + 게이지).
- 설정: 해상도·언어·진동은 드롭다운 모양 버튼(누르면 다음 값), 음량은 초록 슬라이더, 컨트롤러·키보드는
  아이콘 + 제목 + 칩 줄 + `기본값으로 재설정`.
- 상점 뽑기 버튼은 셋 다 초록(값 알약에 코인/캔 아이콘). 뽑기 결과는 노란 트레이 + 피그마 캡슐 그림.
- 배경 패턴(발바닥·별)·로고·코인·캔·기계 3종·캡슐·메달·선물·별·유령 냥이·컨트롤러·키보드 그림은 전부
  피그마 원본(`shared/assets/ui/`)이다.

## 2차 대조에서 나온 질문 (2026-09-28, 폰트·버튼 크기 재점검)

- **우물 폭**: 피그마 우물 틀은 556×1000(x 640)인데, 게임 우물은 10열×20줄이라 높이에 맞추면 틀 폭이
  516이 된다. 틀 위치·색·테 두께는 피그마대로 맞췄고 폭만 40px 좁다. 줄 수를 줄여(19줄) 칸을 키울지,
  지금 폭을 유지할지?
- **팝업 위 유저 HUD**: 피그마 팝업 시안은 화면 전체가 #292929 딤이다. 게임은 좌상단 Lv 카드·재화 알약이
  팝업 딤 위에 그대로 떠 있다(보상 코인이 날아가는 과녁이라 늘 위에 둔다). 팝업 때 HUD도 딤 아래로 내릴지?
- **설정 줄 수**: 피그마 설정은 언어 + 음량 3줄뿐이다. 게임은 해상도(PC) · 진동 줄이 더 있어 줄 간격을
  피그마(118)보다 좁게(98) 쌓았다. 두 줄을 다른 곳으로 옮길지, 지금처럼 둘지?
- **스테이지 모드 3:00 타이머**: 인게임 시안 우물 위에 초시계 3:00 알약이 있다. 지금 스테이지 모드에는
  시간 제한이 없다 — 규칙을 추가하는 것인지, 장식인지?
- **조작 안내 문구**: 시안은 `블록 저장 / 홀드` · `즉시 낙하` 줄이 있는데 게임에는 홀드·하드드롭 키가 없다.
  지금은 실제 키 바인딩(좌우 이동 · 회전 · 점프 · 낙하 가속 · 대시 · 일시정지)으로 그린다.
- **꾸미기 물감 타일 이름**: 시안의 물감 타일은 전부 `커스텀`이다. 게임은 부위 이름(예: 눈 색)을 쓰고
  실제 색을 병 옆 방울로 보여 준다. 색마다 이름을 붙일지?
