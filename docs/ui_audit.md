## 0. 피그마 대조 상태 (먼저 읽을 것)

피그마 시안 맞추기가 최우선인데, **이번 점검에서는 시안을 정밀하게 대조하지 못했다.**

- 피그마 파일(`q0J4VMZ833DcNfGiQRqOSX`)은 연결된 피그마 계정(Braindeck 팀)에 **편집 권한이 없어** 수치(좌표·크기·색·폰트)를 읽는 도구가 거절된다.
- 공개 링크를 브라우저로 여는 것은 되지만 화면이 작게(800×450) 보이고 프레임 이동이 불안정해, 스플래시 1장과 레벨업 팝업 일부만 봤다. 둘 다 지금 게임과 구성이 같았다.
- 그래서 아래 목록은 **게임 화면 자체에서 보이는 문제**(겹침·잘림·불일치) 위주다. "시안과 다르다"는 판정은 넣지 않았다. 시안과의 차이로 이미 알려진 것은 [figma_questions.md](figma_questions.md)에 있다(질문 15개 + 2차 6개, 전부 미결).

**정밀 대조를 하려면 둘 중 하나가 필요하다.**

1. 피그마 파일 소유자가 연결된 계정을 **편집자**로 초대한다(가장 정확, 수치를 그대로 읽는다).
2. 피그마에서 Page 1의 프레임 26장을 PNG(1x)로 내보내 `리소스/figma/`에 넣는다.

확인한 피그마 프레임 목록(Page 1): main, 선택, 모드 선택, 캐릭터 선택 ×3, 게임 플레이, 상점, 랭킹 ×2, 셋팅, 셋팅_컨트롤러 ×2, 셋팅_키보드, 팝업 ×6, 팝업_엔딩, 팝업_레벨업, 일시정지, 선택뽑기 캐릭터, 뽑기결과 ×2. 페이지는 Page 1 / UI kit / _BK.

### 3.2 잘 맞는 것 (확인함)

- 배경(하늘색 + 발바닥·별 패턴), 흰 카드(외곽선 없음), 버튼 3종(초록 주 버튼 / 흰 카드 버튼 / 노란 버튼)의 모양과 눌림 두께는 타이틀·캐릭터·상점·설정·인게임에서 같다.
- 탭(노랑/빨강/회색), 선택 표시(노란 판 + 검은 체크), 재화 알약, Lv 카드는 화면마다 같은 부품이다.
- 가로·세로 모두 같은 색·폰트 체계를 쓴다(Paperlogy 5굵기).

## 4. UX 개선 제안

| # | 화면 | 지금 | 제안 | 효과 |
|---|---|---|---|---|
| U1 | 인게임 | 매달린 블록 위에 작은 흰 숫자(남은 초)만 뜬다 | 숫자를 블록 색 테두리의 원형 게이지로 바꾸고 1초 남으면 깜빡인다 | 언제 떨어지는지 한눈에 |
| U2 | 인게임 조작 안내 | 좌우·회전·점프·낙하 가속·대시·일시정지만 있다 | "▼ 두 번 = 즉시 낙하", "공중에서 점프 = 풍선 점프"를 넣는다. 첫 판 30초 뒤에는 카드를 흐리게 | 숨은 조작 발견 |
| U3 | 스테이지 계기판 | 카드 아래 1/4이 비어 있다 | 그 자리에 "다음 LEVEL: 방해 블록 n줄 / 속도 n단계" 예고를 넣는다 | 빈 자리 활용 + 목표감 |
| U4 | 모드 선택 | 고르지 않은 카드는 회색 데모만 돈다. 모드 설명 글이 없다 | 카드 아래 한 줄 설명 + 내 최고 기록("최고 LEVEL 7", "최고 63층") | 처음 온 사람이 차이를 안다 |
| U5 | 타이틀 | 무대 냥이(이번 판에 나갈 냥이)와 Lv 카드 아바타(대표 캐릭터)가 달라 헷갈린다 | 무대 냥이 아래 이름표("팔레트 · 출전 중")를 단다 | 두 개념 구분 |
| U6 | 상점 | 뽑을 수 없는 이유(골드 부족·품절)가 버튼을 눌러야 나온다 | 버튼을 회색으로 바꾸고 값 알약을 빨갛게, 아래에 "n골드 부족" | 헛누름 방지 |
| U7 | 캐릭터 페이지 | 잠긴 냥이를 눌러도 어디서 얻는지 버튼이 없다 | 상세 카드에 "상점에서 뽑기" 바로가기(유니크는 "주간 랭킹 보상 캔으로") | 다음 행동 안내 |
| U8 | 결과창 | 기록 갱신 여부가 작은 금색 글자 한 줄이다 | 신기록이면 제목을 "신기록이다냥!"으로 바꾸고 통계 판의 해당 칸을 노랗게 | 성취감 |
| U9 | 일시정지 | 음량 조절이 없다 (시안대로 뺌) | 작은 음량 슬라이더 한 줄 또는 "설정" 버튼 (figma_questions 6번) | 게임 중 소리 조절 |
| U10 | 패드·키보드 조작 | 버튼에 포커스 표시가 없다 (`ui_kit.gd`가 버튼의 `focus` 스타일을 빈 것으로 둔다. 실제 패드 조작은 해 보지 않았다) | 포커스 링(노란 4px 테)을 공용 스타일로 넣는다. 스팀 출시에 필수 | 패드만으로 메뉴 이동 |
