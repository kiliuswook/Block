# Cat-Tris 재화 경제 시스템 기획

> 작성일: 2026-07-24. **전 항목 구현 완료** (같은 날). 골드(G)·보석(◆)의 획득/사용 순환 설계.
> 원칙: **골드 = 흔하고 계속 쓰는 소비 재화, 보석 = 희귀하고 아껴 쓰는 프리미엄 재화** (모바일 IAP 확장 대비).

## 1. 현황 진단

### 획득 (구현됨)
| 출처 | 골드 | 보석 |
|---|---|---|
| 엔드리스 사망 정산 | 높이 × 3 | 높이/30층당 1 (최대 3) |
| 엔드리스 줄 클리어 즉시 | 1/2/3/4줄 = 2/5/10/20 | — |
| 스토리 정산 | 점수/20 | 레벨-1 (최대 3) |
| 클래식 정산 | 점수/40 | 2 LEVEL당 1 (최대 3) |
| 신기록 갱신 | — | +1 |

체감 수입: 평범한 엔드리스 1판(~20층) ≈ **90~120G**, 잘 큰 판(40층+) ≈ **200G+, ◆1~2**.

### 사용 (구현됨)
스킨 구매뿐 — 치즈 300G, 회색 500G, 벚꽃 800G(합 1,600G), 황금 ◆20.
→ **전부 사고 나면 싱크가 0.** 재화가 의미를 잃음.

## 2. 설계 목표

1. **반복 싱크**: 한 번 사면 끝이 아니라 매 판/매일 쓰고 싶은 소비처 (골드).
2. **장기 목표**: 수십 판을 모아야 닿는 고가 목표 (골드 대형 + 보석 한정).
3. **밸런스 보호**: 스탯을 돈으로 사지 않음 — 유료 우위는 편의·연출·코스메틱까지만.
4. **플랫폼 확장성**: 보석은 나중에 모바일 IAP로 팔 수 있는 구조 유지 (스팀은 전부 플레이로만 획득).

## 3. 신규 사용처

### 3-1. 부활 젤리 (보석 소비 · 최우선)
이미 UI에 "준비 중" 문구가 있는 기능의 완성.
- 엔드리스 사망 시 이어하기: **1회차 무료(기존 유지) → 2회차부터 ◆2, 회차마다 +1 (◆2→3→4…)**. 판이 끝나면 리셋.
- 스토리 사망 시 이어하기: 스테이지당 1회 무료 → 이후 ◆1 고정 (스토리는 재도전 부담이 낮으므로 저가).
- 의도: 보석의 첫 번째 상시 싱크. "최고기록 목전에서 죽었을 때"라는 최고가치 순간에 소비하게 함.

### 3-2. 냥장품 — 액세서리 상점 (골드 대형 싱크 · 핵심 컨텐츠)
`paint_cat()` 위에 프로시저럴로 겹쳐 그리는 코스메틱 장식. 스킨과 독립 슬롯이라 조합 가능.
- 슬롯 2개: **머리**(모자·리본·왕관…) / **목**(목도리·방울·나비넥타이…).
- 가격 티어: 일반 **200~400G** (6종), 고급 **800~1,500G** (4종), 명품 **3,000G** (2종), 한정 **◆10~15** (2종: 발광·파티클 등 특수 연출).
- 총 골드 싱크 규모 약 **12,000G+** — 스킨 전체(1,600G)의 7배로 장기 목표 확보.
- 스탯 영향 없음(순수 코스메틱). 착용 정보는 `GameState`에 저장, 타이틀 고양이 선택 UI에 상점 탭 추가.

### 3-3. 출발 부스트 (골드 반복 싱크)
판 시작 전 1회성 소비 — Crossy Road식 "매 판 조금씩 태우기".
| 부스트 | 효과 | 가격 |
|---|---|---|
| 워밍업 | 엔드리스 5층에서 시작 (기록·보상은 정상 집계) | 50G |
| 피버 스타트 | 피버 게이지 50% 채우고 시작 | 40G |
| 럭키 젤리 | 이번 판 골드 획득 +50% | 60G |
- 사망 정산 화면에서 "다음 판 부스트" 원터치 재구매 버튼 제공 → 습관화.
- 워밍업은 최고기록 근처(예: 최고기록의 30% 지점)까지로 상한을 둬서 기록 인플레 방지.

### 3-4. 스테이지 스킵권 (보석 · 편의)
스토리 스테이지에서 **연속 3회 실패 시** "◆3으로 건너뛰기" 제안 (클리어 처리, 진행도만 열림 — 별도 마크 표시).
- 막힌 유저의 이탈 방지 + 보석 싱크. 3연패 조건으로 남발 방지.

### 3-5. 간식 주기 — 애정도 (골드 초장기 싱크 · 성장 시스템)
고양이별 애정도 레벨 1~10. **간식 가격이 레벨과 함께 상승**: 50 + 50×레벨 (Lv.1 100G → Lv.9 500G).
레벨업 필요 간식: 1/1/2/2/3/3/4/4/5 (누적 25개) — 고양이당 만렙 총 **9,000G**.
- **능력 성장**: 레벨당 이동·점프·대시 +1% (Lv.10에 +9%). 무게·밀기는 불변. 스탯 핍에 자동 반영.
- **외형 3단계**: Lv.1~4 기본 → Lv.5~9 눈 반짝임 + 진한 볼터치 → Lv.10 크림빛 아우라 + 머리 옆 하트.
- 부가 보상: Lv.5+ 타이틀 화면 통통 모션, Lv.10 이름 옆 ★.
- 9마리 전부 만렙 = 81,000G — 사실상 무한 싱크의 끝점.

## 4. 획득 밸런스 조정 (사용처 확대에 맞춘 소폭 상향)

- **일일 첫 판 보너스**: 그날 첫 게임 정산 골드 2배 (복귀 습관 형성).
- **스토리 스테이지 최초 클리어 보상 명시화**: 스테이지당 골드 20~50 + 10스테이지 구간 보스마다 ◆2 (120스테이지 완주 시 누적 ◆24 — 황금 고양이 ◆20과 자연 연결).
- 보석 수입 총량 가이드: 열심히 플레이 시 **주당 ◆10~15** 수준 유지. 부활(◆2~) · 한정 액세서리(◆10+)와 긴장감 있는 교환비.

## 5. 구현 우선순위

| 순위 | 항목 | 근거 |
|---|---|---|
| 1 | 부활 젤리 유료화 (3-1) | UI 자리까지 있음, 수 시간 작업, 보석에 즉시 의미 부여 |
| 2 | 출발 부스트 (3-3) | 골드 반복 싱크 최속 확보, UI 간단 (사망 팝업/시작 전) |
| 3 | 액세서리 상점 (3-2) | 핵심 골드 싱크 + 볼거리. paint_cat 확장 필요 |
| 4 | 스킵권 (3-4) + 스토리 클리어 보상 (4) | 스토리 경제 연결 |
| 5 | 애정도 (3-5) | 초장기 컨텐츠, 마지막 |

## 6. 코드 접점 메모

- `GameState`: `accessories_owned: Array`, `equipped_acc: Dictionary {head, neck}`, `affection: Dictionary`, `last_daily_bonus: String(날짜)` 추가 + save.json 직렬화.
- 부활 과금: `main.gd._on_revive()` / `death_popup.gd` (가격 표기·잔액 부족 처리), 회차 카운터는 run 상태.
- 부스트: `main.gd` 시작 플로우 → `escape_board.gd` 초기화 파라미터 (시작 높이·피버 게이지·골드 배율).
- 액세서리 렌더: `Player.paint_cat()`에 `acc` 파라미터 추가 (타이틀·인게임 공용이라 한 곳 수정으로 전파).
- 플랫폼: 상점·부스트 UI는 core에 두되 `/platform-split` 체크리스트 준수 — 모바일 세로 레이아웃 별도 확인. IAP(보석 판매)는 추후 `platform/` 피처 태그 뒤에.
